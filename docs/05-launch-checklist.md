# 上线前 50 项检查

这份清单适合 MVP 到生产环境前的最后检查。

## 产品和流程

1. 核心用户流程已完整跑通。
2. 需求边界已确认。
3. MVP 范围没有继续膨胀。
4. 空状态显示正常。
5. 加载状态显示正常。
6. 错误状态显示正常。
7. 重复提交已处理。
8. 核心操作有确认、撤销或补偿机制。
9. 用户首次使用能看到价值。
10. 用户反馈入口已准备。

## 账号和权限

11. 用户注册流程可用。
12. 用户登录流程可用。
13. 用户退出流程可用。
14. 密码或登录凭证安全存储。
15. Token 有过期时间。
16. 后端接口已做权限校验。
17. 管理员接口已单独保护。
18. 普通用户无法访问其他用户或租户数据。

## 前端和体验

19. 核心页面移动端可用。
20. 核心页面桌面端可用。
21. 表单有前端校验。
22. 表单有后端校验。
23. 图片、文件和静态资源路径正确。
24. 错误页面存在。
25. 刷新页面后核心状态可恢复。

## 数据和后端

26. 数据库表结构已确认。
27. 数据库索引已检查。
28. 唯一约束已检查。
29. 数据库迁移脚本已准备。
30. 生产数据迁移前已备份。
31. 核心操作已做幂等。
32. 慢查询已检查。
33. 数据库连接池配置已检查。

## 安全和隐私

34. 环境变量已配置。
35. 密钥没有提交到仓库。
36. HTTPS 已启用。
37. Cookie 安全配置已检查。
38. CORS 配置已检查。
39. 文件上传大小已限制。
40. 文件上传类型已校验。
41. 接口限流已配置。
42. 日志不包含敏感信息。

## 支付、通知和第三方服务

43. 支付回调已测试。
44. 支付幂等已处理。
45. 通知发送失败可重试。
46. 邮件或短信模板已检查。
47. 第三方 API 设置了超时。
48. 第三方 API 失败有降级或补偿方案。

## 测试、监控和发布

49. 单元测试、集成测试或核心链路 smoke test 已通过。
50. 回滚方案、监控告警、上线后观察负责人已明确。

## 最短上线口令

如果只允许保留 10 项，保留这 10 项：

1. 核心链路跑通。
2. 后端权限校验。
3. 密钥不进仓库。
4. 数据库迁移前备份。
5. 核心操作幂等。
6. 所有远程调用有超时。
7. 错误日志可定位。
8. 服务不可用能告警。
9. 发布失败能回滚。
10. 上线后有人盯指标。
